# 📱 1Look & Estimator Tablet Assistant Web App

A responsive Web App version of the 1Look & Estimator Smart Auto-Fill tool, optimized for **iPads, Android Tablets, and Mobile Devices**.

## 🚀 Deployment Options

### Option 1: Deploy to Vercel via GitHub (Easiest)
1. Push this `web_app` folder to a new GitHub repository (or subfolder).
2. Go to [vercel.com](https://vercel.com) and click **Add New Project**.
3. Import your GitHub repository.
4. Click **Deploy**! (Vercel will generate a live URL like `https://your-project.vercel.app`).

### Option 2: Deploy to Vercel CLI
Run the following command inside the `web_app` directory:
```bash
npx vercel
```

---

## 📱 How to Use on iPad / Tablet

1. Open your Vercel URL on iPad Safari or Chrome.
2. Use **Split View** or **Stage Manager** on iPad to place this Web App side-by-side with Safari (`1look.cloud` or `app.remotesf.com`).
3. **1-Touch Quick Copier**: Tap any chip to copy values directly to clipboard on iPad.
4. **1-Click Bookmarklet**: Save the Bookmarklet button to your iPad Safari bookmarks to auto-fill forms with 1 tap!
